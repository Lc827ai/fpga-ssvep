本仓库不保存、也不公开原始人体脑电数据、受试者身份信息或可关联到个人的实验记录。系统开发与演示所涉及的采集数据仅用于项目内部的标定、在线识别验证和结果确认，不作为公开数据集发布。

这一处理方式用于保护受试者隐私，并避免在缺少明确授权、统一标注规范和完整伦理说明的条件下对脑电数据进行二次传播或二次使用。

## 仓库提供的复现材料

仓库提供 FPGA RTL、Vivado 工程、PYNQ 控制程序、PC 监控程序、仿真测试平台、硬件配置文件和实现报告。使用者可按 README 中的步骤连接兼容的 ADS1299 类采集前端，在获得受试者同意并完成安全检查后采集新的数据，完成系统标定和在线验证。

项目在线演示记录的三目标 SSVEP 识别正确率为 80%。该数值用于说明当前系统在既定采集条件下的运行结果，不构成可由本仓库中的公开原始数据独立复算的通用基准。

## 后续数据开放原则

如需后续公开数据，应在获得相应授权后完成去标识化处理，并同时提供采样率、通道顺序、单位、刺激频率、试次标签、标定与测试划分、数据格式和处理版本等必要元数据。
